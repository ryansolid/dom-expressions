Container tier at the slot border (DR-2 case 3): reactive containers (projections) passed as slot args cross as their TRACE — an async iterable whose first yield is a full state snapshot and whose later yields are PatchOp batches, the reactive core's own continuation protocol — and materialize back into live read-only containers on the client, at any depth of an argument, on both faces. New renderer-agnostic glue module (`frame-container-plugin`): the reactive core installs a resolver (server) and a materializer (client); the seroval `ContainerTracePlugin` rides the codec's DEFAULT plugin set, so every serializer face (hydration, frames codec, flight payloads, decode tables) carries it with nothing to wire and its weight stays in the lazy codec chunk. The sink classifies containers FIRST (WeakMap probe — a pending projection's property reads throw not-ready, so async probes would detonate it) and swaps them for serialization envelopes before seroval's own classification can touch them; document-face records carry `{ $tr, $ta }` marker literals revived at arg-read through the new host `revive` hook, memoized per trace. The client mirrors the trap-safe classification (`isMaterializedContainer`, a WeakSet probe) through the new host `isContainer` hook: the record-dedupe compare identity-tests containers instead of probing or stringifying them.
